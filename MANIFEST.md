# MANIFEST — Burn Job Performance Refactoring Engine

## 1. Заявленный уровень (Level)
- **Уровень**: `hard`
- **Описание уровня**: Агент выполняет не только статический и динамический граф-анализ с выгрузкой машинночитаемых находок `findings.json`, но и автоматически генерирует нагрузочные сценарии (`loadtest/api_loadtest_suite.py`), производит итеративный рефакторинг исходного Java-кода с помощью LLM-агента и верифицирует сохранность контрактов с замером метрик «до» и «после».

## 2. Состав артефакта
- **Тип артефакта**: `skill` + `workflow` + `MCP-tool` / `CLI pipeline`
- **Структура**:
  - `skill/`: Инструкции и конфигурация умений агента рефакторинга.
  - `src/burn_job/`: Движок анализа байткода, граф-БД KùzuDB, парсер профайлеров и генератор вариантов кода.
  - `loadtest/`: Нагрузочный генератор (`api_loadtest_suite.py`).
  - `run.sh` & `RUN.md`: Скрипты и инструкция воспроизводимого запуска с нуля.

## 3. Декларация ручных правок
- **Ручная работа**: `0%` (Отсутствует).
- **Автоматизация**: Все детекторы (T1–T9), построение графа вызовов, нагрузочное тестирование, генерация `findings.json`, генерация кода варианта через LLM и компиляционная верификация выполняются полностью автоматически агентным движком.

## 4. Изменения конфигурации и pom.xml
- **`spring.jpa.open-in-view`**: Зафиксировано значение `false` (изменения не производились в соответствии со строгими требованиями регламента).
- **`pom.xml`**: Зависимости и плагины сохранены без изменений.

## 5. Внешние зависимости
- **Python**: `>= 3.10`
- **Зависимости**: `kuzu`, `jinja2`, `llama-cpp-python` (опционально для локального инференса), `typer`, `rich`, `pytest`
- **Java**: JDK 17+
- **Инструменты**: Apache Maven 3.8+
