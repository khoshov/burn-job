# reports/control — статус

По регламенту `SUBMISSION.md` этот раздел **заполняется только если команде выдан control-проект**
(закрытый контрольный проект, который судья использует для второй части оценки:
`итог = sandbox × 0.3 + control × 0.7`).

## Текущий статус

Control-проект команде на данный момент **не выдан** — раздел намеренно пуст. Когда/если он будет
выдан, сюда попадут `findings.json` и `report.md` по той же схеме, что и в `reports/sandbox/`.
